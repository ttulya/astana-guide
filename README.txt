RelaxCaps — запуск и база данных

Сайт находится в папке relaxcaps на рабочем столе.
Запуск: дважды нажмите start.cmd. Откроется http://localhost:3000/profile.html.
Остановка: stop.cmd. После перезагрузки компьютера снова запустите start.cmd.
Сервер запускается в фоне; его сообщения находятся в server.out.log и server.err.log.

Новая база данных: RelaxCapsSiteDB.
SQL Server: LAPTOP-70QJGAQE\SQLEXPRESS (на этом компьютере также .\SQLEXPRESS).
В SSMS выберите «Проверка подлинности Windows» и этот сервер.
В «Базы данных» нажмите «Обновить», затем откройте RelaxCapsSiteDB → Таблицы.
Для просмотра данных откройте database\check-data.sql и выполните запросы.

Что хранится в SQL Server:
- dbo.users: имя, фамилия, телефон, логин, хэш пароля, права администратора;
- dbo.bookings: ID брони, владелец, имя и телефон для связи, дата, время,
  продолжительность, статус, даты создания и изменения;
- dbo.reviews: автор, текст отзыва, оценка, дата;
- dbo.booking_status_history: кто и когда изменил статус;
- dbo.sessions: защищённые сессии входа с ограниченным сроком действия.

Создайте свой аккаунт на странице «Личный кабинет». База новая:
аккаунты из старой RelaxCapsDB автоматически не копируются.
Пароль придумайте самостоятельно: минимум 8 символов (не более 72 байт).
Телефон 87716063124 хранится в нормальном формате +77716063124.
После входа можно редактировать профиль и бронировать посещение.
Новые брони принимаются только на будущее время; длительность — 1–24 часа.
Кабинет показывает только брони вашего аккаунта, даже после изменения телефона.

Администратор:
1. Создайте аккаунт сотрудника на сайте.
2. Дважды нажмите admin.cmd и введите логин этого аккаунта.
3. Откройте admin.html через сайт; там можно менять статусы.
Для снятия прав: node manage-admin.js ЛОГИН --revoke.
Обычная регистрация не выдаёт прав администратора.

Перенос данных из старой браузерной версии:
1. Откройте profile.html как файл в том браузере, где раньше были профиль и брони.
2. Нажмите «Скачать старые данные». Файл не содержит пароль.
3. Откройте http://localhost:3000/profile.html, создайте аккаунт с тем же логином.
4. Войдите и раскройте «Перенести старый профиль и бронирования».
5. Выберите JSON-файл и нажмите «Перенести данные».
Имя и телефон обновятся из файла; старые ID и даты броней сохранятся.
Повторный перенос не создаёт копии. Статусы из неподтверждённого файла
получают значение «Новая»; администратор может проверить и обновить их.
Старые данные в браузере не удаляются автоматически.

Устройство проекта:
HTML + app.js обращаются к локальному Node.js серверу через /api/.
Сервер использует системный Windows SQL-клиент через backend\sql-worker.ps1.
Подключение идёт под вашим Windows-аккаунтом, SQL-пароль не нужен.
Все данные в SQL-запросах передаются параметрами. Пароли хэшируются bcrypt.
Настройки сервера и базы: config.json. Схема создаётся автоматически при запуске.
Используются встроенные средства Windows и Node.js; внешняя зависимость — bcryptjs.

Если проект переносится на другой компьютер:
установите Microsoft SQL Server Express, Node.js 22 или новее,
в папке сайта выполните npm install, укажите свой экземпляр SQL в config.json
и запустите start.cmd. Windows-аккаунту нужны права создания новой базы;
если базу создаёт администратор, учётной записи сайта нужны права на её таблицы.
Текущая конфигурация открывает сайт только на этом компьютере.
SSMS — приложение для просмотра и управления базой; данные хранит SQL Server.
Для публикации в интернете отдельно понадобятся сервер, HTTPS и настройка доступа.

Проверка: node --test tests/integration.test.js.
Тесты создают отдельную временную базу, проверяют регистрацию, вход, права,
брони, статусы, перенос, отзывы и перезапуск, затем удаляют только свою тестовую базу.
tests\ui-preview.js запускает дополнительную тестовую копию на порту 3001.
